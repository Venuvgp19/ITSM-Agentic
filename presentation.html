Multi-LLM Pipeline

Specialized Models Working in Harmony

1. Intelligent Triage & Routing

Model: Meta Llama 3.3 70B

Analyzes incoming tickets, extracts symptoms, assigns target groups (e.g., "App Support"), and sets urgency.

2. Dense Vector Embeddings

Model: NVIDIA nv-embed-v1 (4096-D)

Transforms clean titles and summaries into high-dimensional vectors for semantic cosine similarity matching.

3. Reactive SOP Synthesizer

Model: NVIDIA Nemotron 550B

Synthesizes step-by-step remediation scripts when RAG misses, complete with SSH commands and root causes.

4. Proactive Consolidator

Model: Nemotron / LiteLLM Engine

Background worker that merges duplicate single articles into comprehensive Master SOPs.

Deep Dive: RAG Accuracy Optimization

Overcoming Cosine Similarity Drop (0.0097 → 0.50+)

Initial Bottleneck: Embeddings were generated by including raw JSON shell scripts and unparsed escape sequences. This noise diluted intent semantics, causing valid SOPs to fail RAG matching with scores as low as 0.0097.
Engineering Solution Implemented:
  • Sanitized Text Payloads: Isolated embeddings to ingest purely clean Title + high-level Summary.
  • Calibrated Threshold: Established a strict 0.50 Cosine Similarity threshold to eliminate false positives while guaranteeing semantic precision.

New Feature: Smart SOP Deduplication

Fuzzy Token-Overlap Merging Engine

To prevent the LLM from creating fragmented duplicate KB articles when RAG misses on slightly different titles, we deployed a live fuzzy deduplication layer:

Deduplication Algorithm Flow

  1. Synthesized SOP title is tokenized into core semantic keywords (length > 3).
  2. Calculates Jaccard Token Similarity against all published KBs in PostgreSQL.
  3. If similarity ≥ 60%: Skips creating duplicate KB article.
  4. Appends new SSH commands into existing KB via API PATCH request.
